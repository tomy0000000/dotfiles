# `macos-character-viewer`

Sets the active categories and their order in the macOS Character Viewer (Emoji & Symbols palette), via `defaults write com.apple.CharacterPaletteIM CVActiveCategories`.

## Configures

1. Emoji
2. Latin
3. Greek
4. Parentheses
5. Math Symbols
6. Punctuation
7. Arrows
8. Pictographs
9. Currency Symbols
10. Bullets & Stars
11. Letterlike Symbols
12. Technical Symbols
13. Unicode
14. BIG-5E
